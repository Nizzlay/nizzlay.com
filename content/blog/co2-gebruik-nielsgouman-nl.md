# CO2 gebruik van NielsGouman.nl

Tal van organisaties willen tegenwoordig uitstralen dat ze "groen" zijn. Milieubewust zijn ze bezig met hun bedrijfsactiviteiten, althans dat willen ze ons laten geloven. Meestal zijn het marketing verhalen met weinig echte onderbouwing.

Ik kan me goed vermaken als ik een stukje onderzoek tegenkom waarbij deze claims aan de tand gevoeld worden. Hoe groen is zo'n organisatie dan _echt_? Meestal zijn ze wel aardig bezig op een bepaald gebied wat ze uitlichten in hun marketing, maar slaan ze compleet de plank mis op andere gebieden.

We klagen veel over het nutteloze energieverbruik van crypto's zoals Bitcoin, maar het internet als geheel kan er ook wat van. Tijdens de ontwikkeling van de meeste website word er nauwelijks gekeken naar hoe verspillend deze website is.

Random lijstje met websites. Uiteraard kun je natuurlijk ook de nodige [politieke partijen testen](https://cassee.dev/stuff/verkiezingen-2021-groen) (die het véél slechter doen).

Opvallend is dat greenpeace uit dit lijstje het meeste wil uitstralen dat ze actief zijn voor het milieu, maar het slechtste scoort.

Het mooie is ook dat optimaliseren in dit gebied voor 80% overeenkomt met wat sowieso al best practises zijn voor het maken van een website. Ik heb zelf namelijk nooit geoptimaliseerd voor CO2, maar mijn website scoort alsnog best goed.

1. Zorg voor valide HTML code
2. Gebruik CSS waar het voor bedoeld is
3. Gebruik zo min mogelijk Javascript (nee je hebt dat framework in 90% van de gevallen écht niet nodig)
4. Verminder het aantal plaatjes (meestal voegen ze niets toe aan je verhaal)
5. Laad alleen de fonts die je daadwerkelijk nodig hebt
6. Optimaliseer, minimaliseer, gzip, en zorg dat er zo min mogelijk data opgeslagen hoeft te worden op de server, en nog minder data naar de bezoeker hoeft

Dit word in ieder geval bewezen door mijn nerd vriend die nog verder is gegaan in optimaliseren: [Mijndert](https://mijndertstuij.nl/), met [0.01g](https://www.websitecarbon.com/website/mijndertstuij-nl/).
